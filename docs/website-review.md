# MHK Website Review

## Version 1: 6.5/10

**Pros**
- Brand colours match the business card
- Phone number everywhere: header, hero, sticky mobile button
- Real proof early: licence number, 5.0 stars, Top 10 awards
- Mobile friendly, keyboard accessible, one fast file

**Cons**
1. Empty "Add job photo" boxes made it look unfinished
2. Template feel: label, headline with one highlighted word, card grid, on every section
3. Review cards were paraphrased but looked like real quotes
4. Some claims were stretched ("serving since 2019" was really ServiceSeeking join date)
5. Paint stroke looked like clip art
6. Inverted Google map was heavy and odd
7. Quote form was email only
8. Form errors did not clear after fixing
9. No "how it works" steps, no FAQ
10. No favicon, no link preview tags

## Version 2: 9/10

| Con | Fix |
|---|---|
| Empty photo boxes | Removed. Real photos added later in a Recent Work section |
| Template feel | Every section has its own layout: numbered services list, lime proof block, step timeline, signature style About |
| Clip art stroke | SVG displacement filter gives real brush edges, plus a painted divider |
| Generic hero | Tilted replica of John's actual business card |
| Fake looking reviews | Real 5.0 score, what customers mention most, link to all reviews |
| Stretched claims | "112 jobs booked through ServiceSeeking since 2019", "ServiceSeeking named MHK a Top 10 Painter" |
| Map | Clean suburb list |
| Email only form | Send as text or email. Tapping a service preselects the job type |
| Sticky errors | Clear as you type |
| Missing sections | How a job runs, FAQ, licence verify link |
| Polish | Favicon, Open Graph tags, Call and Text bar on mobile |

## Version 3: real photos added

**What would make it 10/10:** finished "after" photos and before/after pairs from John.
